TMS 1.2.0 - Claude usage strip

Windows 10/11 with Windows PowerShell 5.1 and an interactive Explorer taskbar.
Requires separately installed Claude CLI and the user's own supported account.
Install: double-click Install.cmd. No administrator installation is intended.
Upgrade: close any older strip, then run this version's Install.cmd.
Starts at Windows sign-in; right-click the strip to change that preference.
Left-click the product name to confirm opening the official reset screen.
The strip does not redeem, buy, grant, or count reset coupons.
Drag outside the product-name area to move the strip. Right-click to refresh or exit.
Uninstall: double-click Uninstall.cmd in the installed folder. Account credentials
and saved display preferences are preserved.

The distributed strip uses plain text labels; no provider logos are bundled.

Read SECURITY-AND-DATA.txt in the release before running. The Claude component
uses local Claude Code credentials and an undocumented provider usage endpoint.
Its distribution/use permissions require confirmation before a commercial launch.
The historical token-renewal helper may run a small Claude request and use quota.
Do not enter or send credentials to the TMS seller or Agensi.
