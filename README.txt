TMS - Token Management System 1.2.0

Windows taskbar usage strips for Claude Code and Codex.

Choose claude/Install.cmd, codex/Install.cmd, or both. Each installs to the
current user's LOCALAPPDATA folder and creates Start menu and sign-in shortcuts.
Install CLI dependencies and sign in through their official applications first.
This release does not bundle either provider's CLI, account, subscription or logo.

Features: 5-hour / weekly usage display where returned by the provider; scheduled
refresh; movable strips; full-screen hiding; startup toggle; confirmed navigation
to the official reset screen. It does not consume reset coupons itself.

Claude reset URL: https://claude.ai/settings/usage
Codex reset URL: https://chatgpt.com/settings/usage?tab=overview

Known release limits
- Version 1.2.0 public source release; not a provider-approved or Agensi-approved listing.
- New-machine, reboot and provider-account end-to-end tests remain outstanding.
- Provider permissions for the Claude credential-based monitor remain unresolved.
  Read SECURITY-AND-DATA.txt before a commercial launch.
- This release distributes the Windows utility only. Marketplace eligibility
  and commercial distribution permission remain separate review items.
